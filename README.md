# Webscraping---Facultad
Proyecto realizado en Python para practicar técnicas básicas de Web Scraping utilizando las librerías requests y BeautifulSoup. 

Funcionalidades

Extracción de ofertas de trabajo relacionadas con Python desde una página web.

Obtención del nombre de la empresa, ubicación, puesto y enlace de aplicación.

Extracción de citas y autores desde un sitio web.

Almacenamiento de los resultados obtenidos en un archivo CSV.
